핵심 서비스

K-Insurance는 고팡의 보험 Agent입니다. 아래는 지향하는 방향이며, 현재 실제로 동작하는 것과 아직 개발 중인 것을 구분해 표시합니다.
◆ 고팡은 현실 세계의 AI 쌍둥이들로 구성된 평행 세계입니다.
◆ 사용자의 PDV(개인 데이터 금고)는 동선·일상·업무를 6하원칙으로 기록하도록 설계되어 있습니다. 기록된 항목은 OpenHash에 앵커링되어 위조·변조가 차단됩니다.
◆ K-Traffic은 화물·카풀 매칭 위치 공유가 실제로 동작합니다. 급가속·급제동 등 운전습관 이벤트 감지는 사용자 별도 동의 시에만 기기 안에서 이루어지며(개발 진행 중), 이를 보험료에 반영하는 기능은 아직 개발되지 않았습니다.
◆ K-Health 연동을 통한 자동 실손 청구·인수 심사 기능은 아직 개발되지 않았습니다.
◆ OpenHash 앵커링은 기록된 데이터의 위·변조를 막아주지만, "보험 사기가 구조적으로 불가능"해지는 것은 아닙니다 — 애초에 잘못 기록되거나 기록되지 않은 사실까지 막아주진 않습니다.
◆ 현재 청구 심사는 담당자 검토로 이루어집니다. AI(DeepSeek V4 Pro·Claude Opus)를 심사에 활용하는 자동화는 아직 개발되지 않았습니다.
◆ 배상 책임 판단에 K-Law를 참조로 활용하는 것은 향후 계획입니다.

목표는 실제 삶의 데이터가 보험료에 정직하게 반영되는 구조입니다. 모든 소스코드와 AI 시스템 프롬프트는 GPL v3.0 오픈소스입니다.

K-Traffic 탑승, K-Market 배달, K-119 응급 이벤트 감지 시 자동 보험 적용을 목표로 설계 중입니다.

개발 중
PDV 6하원칙 기록

기록된 항목은 OpenHash 앵커링으로 위변조가 차단됩니다. 사고 증거 자동 구성은 개발 중입니다.

청구 접수는 지갑 서명 기반으로 실제 동작합니다. 심사는 담당자가 검토 후 별도 안내드립니다.

담당자 검토
K-Traffic 매칭 (실제 동작)

화물·카풀 위치 공유 매칭은 실제로 동작합니다. 운전 이력의 보험료 반영은 개발 중입니다.

일부 구현
K-Health 연동 (개발 중)

진료 이력 기반 건강보험 인수 심사·실손청구 연동은 아직 개발되지 않았습니다.

개발 중
기록 위변조 방지

PDV·K-Traffic·K-Health에 실제로 기록된 항목은 OpenHash 앵커링으로 위변조가 차단됩니다. 청구-기록 자동 대조·K-Police 연동은 개발 중입니다.

일부 구현

당신의 삶이 보험료를 결정합니다

PDV · K-Traffic · K-Health — 세 가지 데이터 금고가 보험의 모든 것을 처리합니다.

고팡의 모든 데이터는 OpenHash 분산원장에 앵커링됩니다. 기록된 항목은 사용자 본인도, 고팡 팀도, 어떤 해커도 수정할 수 없습니다. 다만 이것이 곧 "보험료를 자동으로 산정하는 기능이 있다"는 뜻은 아닙니다 — 그 연동 기능은 아직 개발 중입니다.

◆ 목표(개발 중) — 실제 삶의 데이터를 반영해 역선택을 줄이는 것이 지향점입니다. 다만 어떤 데이터를, 어떤 방식으로, 어떤 한도까지 반영할지는 신중한 설계가 필요합니다 — 특히 건강 데이터를 개인 보험료에 직접 연결하는 것은 여러 나라에서 유전정보 차별 등의 문제로 규율되는 민감한 영역이라, 별도 검토 없이는 반영하지 않습니다.
◆ 기록의 위·변조 방지 — 실제로 기록된 항목이 사후에 조작되는 것은 OpenHash 앵커링으로 차단됩니다. 다만 청구와 기록을 자동으로 대조해 사기를 판별하는 기능은 아직 개발되지 않았습니다.

PDV (Private Data Vault) — 전생애 동선·행동 기록

사용자 기기에 암호화 저장 · OpenHash 해시만 서버 보관 · 6하원칙 구조화

OpenHash 앵커
사고 즉시 증거 구성 (개발 중)사고 시각·장소·경위를 6하원칙으로 자동 추출해 청구 서류를 생성하는 기능은 아직 개발되지 않았습니다.
생활 패턴 리스크 반영 (미정)생활 패턴을 보험료 계수로 환산하는 기능은 설계 단계이며, 반영 여부·범위 모두 확정되지 않았습니다.
사기 탐지 (개발 중)청구 내용과 PDV 기록의 자동 대조·K-Police 연동은 아직 개발되지 않았습니다.
고팡 서비스 행위 기록결제·이동·주문·대화 등은 PDV 설계상 기록 대상이나, 서비스별 실제 연동 범위는 각 서비스 진행 상황에 따라 다릅니다.

K-Traffic PDV (traffic.hondi.net) — 차량 이용 이력

화물·카풀 매칭 위치 공유는 실제 동작 · 운전습관 이벤트 감지는 사용자 동의 시 개발 중

OpenHash 앵커
교통사고 청구 증거 (개발 중)사고 시각·경로 데이터를 청구 증거로 자동 연동하는 기능은 아직 개발되지 않았습니다.
운전습관 이벤트 감지 (동의 기반, 개발 중)급가속·급제동 이벤트를 사용자 별도 동의 시 기기 안에서 감지하는 기능을 개발 중입니다. 원시 센서값은 전송되지 않고 등급 정보만 기록됩니다. 이를 보험료 할인·할증으로 환산하는 요율은 아직 확정되지 않았습니다 — 여기 표시하던 구체적 배수(예: ×1.30)는 실제 요율이 아니라 지어낸 예시였습니다.

K-Health 연동 — 개발되지 않음

진료·처방·수술 이력을 보험에 연동하는 기능은 아직 없습니다

K-Health 진료기록 기반 실손보험 자동 청구, 기왕증 자동 판별, 건강 이력에 따른 보험료 할인·할증 — 전부 아직 개발되지 않았습니다. 이전 버전에는 "고혈압·당뇨 등 ×1.20~1.50" 같은 구체적 계수가 실제 요율표처럼 표시되어 있었는데, 지어낸 예시였을 뿐 아니라 애초에 개인 건강정보를 이런 방식으로 개인 보험료에 직접 연결하는 것 자체가 신중한 법률·윤리 검토 없이는 하지 않기로 한 영역입니다.
